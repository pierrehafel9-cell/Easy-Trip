# Images

Déposez vos visuels ici. Fichiers attendus :

- `logo.png` ou `logo.svg` — Logo Easy Trip (déjà un SVG d'aperçu fourni)
- `hero.jpg` — Photo principale de l'accueil (1920×1080 conseillé)
- `kit-main.jpg` — Photo du Kit M installé dans un véhicule
- `kit-lit.jpg`, `kit-cuisine.jpg`, `kit-rangements.jpg` — Détails du kit
- `accessoires/*.jpg` — Photos des accessoires (glacière, douche, etc.)

Le site utilise des "media-placeholder" en CSS tant que les images réelles ne sont pas déposées. Une fois vos photos en place, remplacez les `<div class="media-placeholder">` par des `<img src="assets/img/...">` dans le HTML correspondant.
